## Notes
- Promotions are implemented as **promo codes only**. The BRS "Sale" concept (product/category scope, window, discount type/amount, lifecycle status) has no domain model, commands or table.
- `AdminPromoCodeController` writes SQL directly from the HTTP layer instead of dispatching a command; this is an architecture-conformance finding, recorded in the consolidated report, not a business gap.
- Root-category label uniqueness is enforced by slug uniqueness plus tree validation for subcategories; the BRS sibling rule is satisfied for the stored hierarchy.
