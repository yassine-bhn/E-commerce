# Spec: Close F-csrf-origin-guard — path-decode parity (S1), shared Origin/OriginAllowList, ADR-0013 correction, review re-run, GATE DONE
Version: 1
Analyst: C (skeptic)

## Goal
Ship the round-1 FIXES plan so the percent-encoded-path CSRF bypass is closed (the guard judges the same decoded path Symfony routes on), the origin trust policy lives in one shared Domain value-object pair consumed by both the guard and `CorsSubscriber`, ADR-0013 stops overstating the control, the re-run review fan-out is clean, and the task state file reaches GATE DONE per `.agents/orchestration.md` and the AGENTS.md Definition of Done.

## Corrected prompt
The shipped `CrossSiteRequestGuardSubscriber` refuses cross-site state-changing `/api/v1` requests, but round-1 security review returned DO-NOT-SHIP (S1): the guard matches the raw `Request::getPathInfo()` while Symfony's `UrlMatcher` matches `rawurldecode($pathInfo)`, so percent-encoded spellings of `/api/v1` (`/api%2Fv1/...`, `/api/%76%31/...`) route normally and skip the guard — verified on the running stack (plain path 403, encoded spellings 401 at the firewall). Continue the FIXES plan recorded in `.agents/state/F-csrf-origin-guard.md` under "FIXES plan (round 1)", keeping its locked decisions:

- FIX-2 (production): decode the request path exactly once with `rawurldecode()` in the guard, mirroring `UrlMatcher::doMatch()`; extract a shared `Origin` value object and `OriginAllowList` into `src/Shared/Domain/Http/`, consumed by both `CrossSiteRequestGuardSubscriber` and `CorsSubscriber` (`CorsSubscriber` keeps echoing the raw `Origin` header value so browser comparison is unchanged); move the guard's `kernel.request` priority from 16 to 14 (16 collides with `MalformedRememberMeCookieSubscriber` and `LocaleListener`); stop re-splitting/re-parsing the allow-list per request (P1); add unit tests for the two new Domain classes.
- FIX-3 (docs): update `docs/adr/ADR-0013-session-cookie-credential.md` — S2: state the raw-path caveat instead of overstating the control; S4: the allow-listed origin becomes a write trust anchor; S5: "own origin" derives from `Host`/`X-Forwarded-Host`, trusted proxies decide.
- FIX-1 (tests) is already written: `tests/Functional/CsrfOriginGuardTest.php` currently has exactly 2 failures, both the S1 bypass expectations (`/api%2Fv1/...` and `/api/%76%31/...` expecting 403); they must be green after FIX-2 without weakening the existing pins.

Then re-run the review fan-out (code, architecture, security, performance, test reviewers, plus solid-guardian on the design-bearing diff) and, if clean, close the task: GATE REVIEW ok, extended coverage table, GATE DONE per `.agents/orchestration.md` and the AGENTS.md Definition of Done.

Out of scope, recorded in the task state and not to be fixed here: `LoginAuthenticator::supports()` raw-path comparison; the 20 leftover `csrf-*` rows in `app_test.processed_commands`; the OPTIONS preflight mutation limitation; infection (the image has no coverage driver).
